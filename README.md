# 1 Crore Coach — Hybrid High-Converting Masterclass Funnel

A high-converting, modern dark-glow masterclass and coaching landing page built with an aesthetic fusion of:
- **Funnelra**: Obsidian dark styling, gold-amber accents, glassmorphic cards, glowing borders.
- **Esckul**: Live urgency pill header, real-time countdown timer, interactive 3-day curriculum breakdown tabs.
- **Leadclass**: Video Sales Letter (VSL) container, comparison decision matrix, structured FAQ accordion, sticky bottom conversion bar.
- **1 Crore Coach Offer Architecture**: Complete copy, bonuses, mentor profile, trust proof badges, and ₹99 ticket pass registration flow.

## 🚀 Live Demo & Local Run
To preview locally:
```bash
python -m http.server 8085
```
Open [http://localhost:8085](http://localhost:8085) in your browser.
